# Документация

- Пользовательская документация, комментарии и сообщения проверок пишутся на русском, кроме машинных идентификаторов и названий протоколов или API.
- Канонические долговечные знания находятся в каталоге проекта `docs/` и индексируются из `docs/INDEX.md`.
- ADR фиксирует контекст, решение, последствия и статус.
- README объясняет эксплуатацию без необходимости читать реализацию.
- Изменяемые локальные сводки не подменяют долговечную документацию.
