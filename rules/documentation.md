# Documentation

- Пользовательская документация, comments и validation messages — на русском, кроме machine identifiers и protocol/API names.
- Canonical durable knowledge находится в project `docs/` и индексируется из `docs/INDEX.md`.
- ADR фиксирует контекст, решение, последствия и статус.
- README объясняет эксплуатацию без необходимости читать implementation.
- Mutable local summaries не подменяют durable documentation.
