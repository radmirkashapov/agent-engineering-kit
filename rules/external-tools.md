# Внешние инструменты

Внешние компоненты объявляются в `catalog/`, фиксируются в `locks/`, устанавливаются в локальное хранилище машины и активируются только после проверки. Запрещено включать их исходный код в репозиторий, неявно следовать за `latest` или считать успешную загрузку достаточной проверкой. Предыдущая активная ревизия сохраняется для отката.
