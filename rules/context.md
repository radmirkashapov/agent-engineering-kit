# Контекст

Приоритет от низшего к высшему:

1. значения исходного поставщика;
2. глобальный набор;
3. закоммиченная конфигурация проекта;
4. глобальные локальные переопределения пользователя;
5. локальные переопределения пользователя для проекта.

Закоммиченный проектный слой не может ослабить корпоративную основу. Владелец машины может локально расширить, заменить или отключить skill и MCP, включая элементы `enforced`, `locked` и `required`; такое решение действует только в effective-конфигурации машины и не меняет Git. Локальная модель не становится допустимой для закоммиченного определения. В начале сеанса фиксируется ревизия набора; активная задача не переключается на новую ревизию посередине работы.
