# Контекст

Приоритет от низшего к высшему:

1. значения исходного поставщика;
2. глобальный набор;
3. закоммиченная конфигурация проекта;
4. глобальные локальные переопределения пользователя;
5. локальные переопределения пользователя для проекта.

Более высокий слой не может ослабить обязательную или заблокированную политику, отключить обязательную проверку или сделать пользовательскую локальную модель допустимой для закоммиченного определения. В начале сеанса фиксируется ревизия набора; активная задача не переключается на новую ревизию посередине работы.
