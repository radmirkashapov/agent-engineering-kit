# Модели

- Закоммиченные роли агентов, skills и конфигурации проверяются только по непустому `models/corporate.yaml`.
- `models/user.local.yaml` никогда не попадает в Git.
- При пустом корпоративном списке пользовательские локальные модели допустимы только в локальной среде выполнения.
- Skills объявляют необходимые способности; явный ID модели используется лишь при необходимости.
- Псевдоним не обходит список разрешённых моделей: механизм разрешения всегда приводит его к корпоративной модели.
- CI не читает пользовательскую локальную политику.
