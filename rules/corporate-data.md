# Корпоративные данные

- Определи класс данных до обращения к корпоративному MCP. Используй только классы, разрешённые для конкретной возможности в корпоративном каталоге.
- Запрашивай минимальный объём, необходимый для текущей задачи: ограничивай поля, строки, временной диапазон и количество результатов.
- Передавай данные только на совместимый и одобренный для этого класса конечный пункт модели. При отсутствии подтверждённой совместимости не отправляй содержимое модели.
- Удаляй персональные данные, токены, ключи, пароли и иные секреты из аргументов, ответов, журналов и итоговых отчётов. По возможности сохраняй только метаданные и ссылку на источник.
- Не сохраняй сырые корпоративные результаты в репозитории, памяти проекта или временных материалах после завершения задачи. Удаляй временные копии в рамках разрешённой области задачи.
- Отмечай происхождение использованных данных: систему, объект, время получения и выбранную возможность MCP без раскрытия чувствительного содержимого.
