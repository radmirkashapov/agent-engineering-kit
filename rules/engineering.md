# Разработка

- Сначала установи границы логического проекта и затронутых компонентов.
- Предпочитай минимальное связное изменение с явным контрактом.
- Не копируй глобальные правила, skills или определения MCP в рабочие репозитории.
- Не смешивай репозиторий, среду выполнения, локальную память проекта и нативное состояние MCP.
- У любого сгенерированного артефакта должны быть владелец, источник и способ воспроизведения.
- Формируй переносимые пути через API платформы; не зашивай домашние каталоги в код.
