# Engineering

- Сначала установи границы logical project и затронутых components.
- Предпочитай минимальное связное изменение с явным contract.
- Не копируй global rules, skills или MCP definitions в рабочие repositories.
- Не смешивай repository, runtime, local project memory и MCP-native state.
- Любой generated artifact должен иметь owner, source и способ воспроизведения.
- Сохраняй cross-platform paths через platform APIs; не зашивай home directories.
