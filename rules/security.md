# Безопасность

- Секреты допускаются только через переменные окружения или внешнее хранилище секретов.
- В закоммиченной конфигурации сохраняй `env:VARIABLE`, но никогда не само значение.
- Обязательные требования безопасности нельзя ослабить локальным переопределением.
- Корпоративная политика моделей является авторитетной для закоммиченных определений.
- Перед коммитом запускай `agent-kit validate git-hygiene` и `agent-kit validate security`.
- Не печатай секреты в журналах, выводе `doctor` и диагностических отчётах.
