# Cline

Cline использует тонкий мост через `AGENTS.md`, Cline Rules и нативные настройки MCP. Точные глобальные пути и поддержка skills зависят от версии клиента или расширения, поэтому `resync` не перезаписывает недокументированный пользовательский путь. Сгенерированное состояние фиксирует путь, выбранный механизмом разрешения, а контракт явно описывает это ограничение.
