# Codex / Codex Desktop

Thin adapter использует global `~/.codex/AGENTS.md`, user skills в `~/.agents/skills` и MCP в `~/.codex/config.toml`. CLI, IDE extension и Desktop разделяют Codex configuration. Generated links указывают на effective skills, а project instructions остаются иерархическими. Источники: [AGENTS.md](https://developers.openai.com/docs/agent-configuration/agents-md), [MCP](https://developers.openai.com/docs/extend/mcp), [Skills](https://developers.openai.com/docs/build-skills).
