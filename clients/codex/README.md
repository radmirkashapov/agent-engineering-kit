# Codex / Codex Desktop

Тонкий адаптер использует глобальный файл `~/.codex/AGENTS.md`, пользовательские skills в `~/.agents/skills` и MCP в `~/.codex/config.toml`. CLI, расширение IDE и Desktop используют общую конфигурацию Codex. Сгенерированные ссылки указывают на итоговый набор skills, а инструкции проекта сохраняют иерархию. Источники: [AGENTS.md](https://developers.openai.com/docs/agent-configuration/agents-md), [MCP](https://developers.openai.com/docs/extend/mcp), [Skills](https://developers.openai.com/docs/build-skills).
