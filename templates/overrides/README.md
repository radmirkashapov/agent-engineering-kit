# Нейтральные локальные переопределения

Этот каталог содержит исходные шаблоны для первого запуска. `resync` копирует только отсутствующие файлы в локальное хранилище пользователя и никогда не заменяет уже существующие данные.

Файлы с суффиксом `.yaml.example` служат готовыми примерами. Переименуйте нужный файл в `.yaml` только после проверки его параметров: пока суффикс сохранён, resolver его не применяет.
