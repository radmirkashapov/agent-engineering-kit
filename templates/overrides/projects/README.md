# Переопределения отдельных проектов

Создайте в этом каталоге папку с ID логического проекта и поместите в неё `access.yaml`, `mcp` или `skills`. Такие значения имеют приоритет над глобальными: они могут отключить любой компонент, включая required, locked и enforced, но не могут повторно разрешить компонент, заблокированный на глобальном уровне. Корпоративные проверки репозитория остаются обязательными.
