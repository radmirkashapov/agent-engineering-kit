# Назначение
Статически анализирует структуру и инструкции skills.
# Почему используется
Специализированный анализ дополняет универсальные сканеры.
# Модель угроз
Подозрительные инструкции, обфускация и рискованное содержимое skill; кандидат не выполняется.
# Источник
Официальный `NVIDIA/SkillSpector`, Apache-2.0; точный коммит закреплён в lock-файле.
# Поддерживаемые платформы
Среда выполнения Python на macOS, Linux и Windows.
# Установка
Закреплённая ревизия Git через `uv tool install`.
# Проверка
Запускается SkillEvaluator через явно заданный исполняемый файл.
# Обновление
Кандидат → сканирование → проверка lock-файла → активация.
# Откат
Восстановить предыдущий lock-файл и установку инструмента.
# Удаление
Удалить локальный корневой каталог инструмента.
# Разрешения
Повышенные привилегии не нужны; доступ к кандидату только на чтение.
# Доступ к сети
Сеть нужна только при установке; базовая среда выполнения работает без сети.
# Интеграция с agent-kit
Обязательный блокирующий сканер внешних skills.
# Ограничения
Эвристики допускают ложные срабатывания и требуют ручной проверки.
