# Назначение
Инвентаризация компонентов машины и проверка открытых поверхностей в среде AI-разработки.
# Почему используется
Показывает поверхность цепочки поставки после первоначальной установки, обновлений и во время расследования инцидентов.
# Модель угроз
Неожиданные агенты, MCP, skills и открытые поверхности; инструмент не предназначен для исследований или проверки skills.
# Источник
Официальный `perplexityai/bumblebee`, Apache-2.0, точная ревизия в lock-файле.
# Поддерживаемые платформы
macOS и Linux; Go 1.25+. Windows получает состояние `NOT_SUPPORTED`, а не `PASS`.
# Установка
Закреплённый `go install` в локальное хранилище машины.
# Проверка
Инвентаризация по запросу после первоначальной установки или обновления набора инструментов.
# Обновление
Через проверенный lock.
# Откат
Переустановить предыдущую закреплённую версию.
# Удаление
Удалить управляемый исполняемый файл и его состояние.
# Разрешения
Повышенные привилегии не нужны; доступ к местам инвентаризации только на чтение.
# Доступ к сети
Сеть нужна при установке; доступ во время выполнения зависит от выбранных проверок.
# Интеграция с agent-kit
Необязательный компонент диагностики и инвентаризации, не блокирующий активацию.
# Ограничения
Проект ещё молод; поддержка платформ ограничена.
