# Назначение
Статически анализирует исполняемый код внутри skills.
# Почему используется
Находит опасные шаблоны работы с процессами, файловой системой и сетью там, где анализа только Markdown недостаточно.
# Модель угроз
Вредоносный или небезопасный встроенный код; смысл Markdown анализируется не полностью.
# Источник
Официальный `semgrep/semgrep`, LGPL-2.1; версия пакета и коммит закреплены.
# Поддерживаемые платформы
macOS, Linux и Windows в поддерживаемой среде Python.
# Установка
Закреплённая версия PyPI через изолированную установку `uv tool`.
# Проверка
Запускается из профиля безопасности SkillEvaluator.
# Обновление
Только после обновления lock-файла и теста совместимости.
# Откат
Повторно установить предыдущую версию пакета.
# Удаление
Удалить локальный корневой каталог инструмента.
# Разрешения
Повышенные привилегии не нужны; сканирование выполняется только для чтения.
# Доступ к сети
Базовая среда выполнения работает без сети; облачные правила не используются.
# Интеграция с agent-kit
Проверка блокирует активацию при наличии кода; применимость фиксируется в результатах.
# Ограничения
Без подходящих правил не доказывает безопасность.
