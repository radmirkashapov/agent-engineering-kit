# Цепочка поставки

Источник из каталога вместе с полной 40-символьной ревизией в lock-файле определяет идентичность компонента. Устанавливай кандидатов вне репозитория, сохраняй предыдущую проверенную ревизию для отката и запускай Bumblebee для инвентаризации машины после первоначальной установки или изменения набора инструментов.
