# MCP

Для MCP действует принцип минимальных привилегий. Учётные данные задаются через сопоставления переменных окружения, удалённый OAuth остаётся под контролем клиента, а нативные базы и кэши принадлежат соответствующему MCP. Условные серверы активируются только по признакам проекта или окружения.
