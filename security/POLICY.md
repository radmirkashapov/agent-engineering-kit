# Политика безопасности

Секреты, учётные данные, внешние деревья исходного кода, исполняемые файлы, состояние OAuth и локальные пути машины не коммитятся. Загрузки закрепляются полной ревизией или неизменяемой версией пакета. Кандидаты проверяются до атомарной активации; отклонённый кандидат остаётся в состоянии `BLOCKED` и не может заменить предыдущую ревизию `ACTIVE`.

Skills из внешнего источника проходят блокирующие проверки безопасности, персональных данных, лицензий, целостности кода, Unicode и зависимостей. Проверки схемы, качества и оформления от SkillEvaluator, предназначенные только для публикации, записываются отдельно, но не блокируют использование, если во внешнем диалекте Agent Skills нет специфичных для публикации NVIDIA метаданных. Набор независимо проверяет имена, обязательные способности и границы.

Рассмотрение ложных срабатываний привязано к ревизии и коду замечания: принятые коды SkillSpector перечисляются в каталоге skills только для точного неизменяемого коммита. Любой новый код или новая ревизия блокирует активацию. Замечания уровня `CRITICAL` и замечания Gitleaks этим механизмом никогда не принимаются. Итоговое состояние записывает `PASS_WITH_REVIEWED_FINDINGS` и локальный путь к отчёту.
