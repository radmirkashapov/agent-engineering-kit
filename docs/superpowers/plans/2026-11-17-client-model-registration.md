# План реализации централизованной регистрации моделей

> **Для агентных исполнителей:** выполняйте план последовательно, отмечая завершённые шаги флажком (`- [ ]`).

**Цель:** Централизованно зарегистрировать объявленные пользовательские модели в безопасных конфигурациях клиентов, не читая и не перезаписывая credentials.

**Архитектура:** Расширить схему каталога моделей, сохранив текущую семантику объединённой policy. Добавить изолированный сервис `client_models`, который владеет только явно помеченными блоками provider в Codex/OpenCode, и CLI-обёртку; `resync` вызывает сервис после публикации adapters.

**Технологии:** Python 3.10+, PyYAML, JSON/JSONC, безопасная работа с TOML-текстом, pytest.

**Spec:** `docs/superpowers/specs/2026-11-17-client-model-registration-design.md`

## Общие ограничения

- Никогда не читать, не печатать, не копировать, не заменять и не удалять значение credentials.
- Изменять разрешено только Codex и OpenCode.
- Сохранять чужую конфигурацию клиента и отклонять конфликты владения.
- Вся пользовательская документация пишется по-русски; описания компонентов по умолчанию остаются английскими.
