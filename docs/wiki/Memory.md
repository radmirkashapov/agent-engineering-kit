# Память и индексация кода

Локальная память логического проекта и нативные базы MCP — разные области. Kit хранит пространство имён проекта и отчёты о связях; `Codebase Memory` и `Serena` владеют собственными индексами вне Git. Такое разделение сохраняет данные проекта и состояние инструментов независимыми.

## Codebase Memory и Serena

| Инструмент | Используйте для |
|---|---|
| Codebase Memory (CBM) | Архитектуры, вызовов функций, связей и анализа влияния |
| Serena | Точного поиска символов, ссылок и семантического редактирования |

Для широкой области начните с `Codebase Memory`, затем уточните символы через `Serena`. Первый инструмент помогает понять связи и возможные последствия правок, второй — найти точные места в исходниках. Не запускайте широкий параллельный поиск обоими без необходимости.

## Обновление индексов

При `project init` Kit индексирует каждый доступный репозиторий: полный граф `Codebase Memory` и символы `Serena`. Перед управляемым запуском через `run prepare`, высокоуровневую команду `agent task create` или создание lane выполняется быстрое обновление. После работы внешнего клиента запустите:

```bash
agent-kit project memory-refresh
```

Индексация также запускается после `task complete` и `lane complete`, когда изменения интегрированы. Сводка сохраняется в `<data>/projects/<project-id>/integrations/memory-index.json`.

В smoke-проверке команда завершилась с кодом 0, но оба indexer были помечены как `SKIPPED`: MCP оказались отключены или исполняемые файлы недоступны. Это значит, что индекс фактически не обновился. Включите и проверьте MCP, затем повторите `agent-kit project memory-refresh`.

## Диагностика

- Проверьте `agent-kit project status` и наличие всех обязательных репозиториев.
- Проверьте установку средств командами `agent-kit mcp status` и `agent-kit mcp explain codebase-memory` либо `serena`.
- В проекте из нескольких репозиториев проверьте локальные привязки.
- При ошибке или пропуске indexer не считайте старый индекс свежим.

Не коммитьте нативные индексы и базы: они создаются и обновляются самими инструментами. Описание их границ доступно в [руководстве по MCP](https://github.com/radmirkashapov/agent-engineering-kit/blob/main/mcp/README.md); см. также [логические проекты](Projects).
