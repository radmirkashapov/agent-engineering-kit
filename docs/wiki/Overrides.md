# Локальные переопределения и `ACL`

Локальные переопределения позволяют владельцу машины настроить итоговую конфигурацию вне Git. Они не изменяют корпоративную или проектную основу и не разрешают включать секреты в коммиты. Это способ учесть личную рабочую среду, не превращая её настройки в общее правило команды.

## Расположение и приоритет

Глобальные пользовательские настройки находятся в `<data>/overrides/global/`, проектные — в `<data>/overrides/projects/<project-id>/`. Приоритет от низшего к высшему:

```text
исходный поставщик < глобальная база < проект < глобальные настройки пользователя < настройки пользователя для проекта
```

Поддерживаются режимы `extend`, `replace` и `disable`. Для каждого решения указывайте причину; схема проверяется до активации.

```bash
agent-kit override list
agent-kit override explain skills <skill-id>
agent-kit override set skills <skill-id> \
  --mode disable \
  --from ./override.yaml \
  --reason 'локальная причина' \
  --scope global
agent-kit override reset skills <skill-id> --scope global
```

Формат YAML зависит от типа сущности. Перед применением проверьте `agent-kit help override set` и соответствующую схему. Поддерживаются типы `agents`, `approvals`, `harness`, `mcp`, `models`, `network`, `rules`, `sandbox`, `skills` и `tools`.

## ACL и capability policy

Профиль задаёт договор доступных возможностей, а не произвольную гарантию защиты. `planned_capabilities` — запрошенный набор; `enabled_capabilities` — то, что клиент действительно применил. Сервер MCP, совмещающий чтение и запись, нельзя считать доступным только для чтения, если клиент не ограничивает его инструменты. См. [профили и роли](Profiles-and-roles).

Владелец машины может локально расширить, заменить или отключить элемент, включая пометки `enforced`, `locked` и `required`. Это не переписывает Git и не меняет проверки CI для переносимой основы. Корпоративная политика моделей продолжает ограничивать закоммиченные роли, навыки и описания клиентов.

Для диагностики происхождения используйте `override explain`, `skills explain`, `mcp explain` и `config explain`. Затем проверьте `agent-kit validate overrides`. Значения секретов запрещено помещать в личные переопределения.
