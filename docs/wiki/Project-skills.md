# Репозиторий project-skills

Project-skills — общий Git-репозиторий пользовательских и проектных навыков для логического проекта. Все продуктовые репозитории с одним `project.id` получают одинаковый набор; проекты с разными ID независимы. Так команда получает единый источник инструкций, не дублируя их по каждому коду.

Kit хранит локальную управляемую копию вне продуктовых репозиториев. Исходники навыков не копируются в `.ai-team/` или отдельные проекты. Описание проекта содержит ссылку и параметры источника; удалённый Git-репозиторий остаётся источником истины.

## Выбор ветки

По умолчанию используется основная ветка источника. Рабочую ветку подключают локально:

```bash
agent-kit project skills status
agent-kit project skills use-branch feature/search
```

Вернуться к основной ветке:

```bash
agent-kit project skills use-main
```

Выбранная ветка сохраняется локально для логического проекта, а не в Git продуктового репозитория. Публикация изменений выполняется обычными средствами Git: ветка, коммит, PR/MR и проверки. Этот порядок сохраняет привычный контроль изменений и делает версию набора воспроизводимой для участников команды.

## Приоритет и обновление

Project-skills участвуют в общей модели происхождения: исходный поставщик, общая база, проектный набор и локальные настройки пользователя. Состояние, ревизию источника и коллизии смотрите в `agent-kit project skills status`; итог отдельного навыка — в `agent-kit skills explain <id>`. Для применения новой ревизии используйте `agent-kit resync`. При проблеме с новой версией предыдущий рабочий набор сохраняется.

Текущая версия командной строки предоставляет `use-branch`, `use-main` и `status`. Публикация и изменение содержимого репозитория выполняются средствами Git, а не командами Kit. Доступные действия можно проверить командой `agent-kit help project skills`.

## Безопасность и диагностика

- Источник и `ref` должны соответствовать схеме; не добавляйте учётные данные в URL.
- Новая версия проходит проверку до активации.
- При отсутствии сети можно работать с уже активной локальной ревизией, если она установлена.
- Изменения интерфейса проверяйте командами `agent-kit validate project-skills` и `agent-kit security scan`.
