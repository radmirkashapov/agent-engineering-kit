# ADR 0002: желаемое состояние и `resync`

Статус: принято.

Каталоги описывают желаемое состояние, lock-файлы — одобренные неизменяемые ревизии, а локальное состояние — фактическое состояние машины. `agent-kit resync` сравнивает их, устанавливает кандидатов, проверяет и только затем атомарно активирует. Повторный запуск идемпотентен.
