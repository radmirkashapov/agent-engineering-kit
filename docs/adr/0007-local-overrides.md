# ADR 0007: локальные переопределения

Статус: принято.

Переопределения находятся вне рабочей копии и поддерживают режимы `extend`, `replace` и `disable`. Приоритет: исходный источник < набор < закоммиченная конфигурация проекта < глобальная конфигурация пользователя < конфигурация пользователя для проекта.

Владелец машины может локально заменить или отключить любой skill и MCP, включая элементы `required`, `locked` и `enforced`. Эти признаки описывают рекомендуемый базовый профиль и позволяют показать предупреждение, но не отнимают локальный контроль. Итоговая конфигурация проверяется схемой до активации.

Локальная свобода не изменяет корпоративную основу: overrides находятся вне Git, CI не читает их, секреты остаются только в переменных окружения или внешнем хранилище, а пользовательские модели не становятся допустимыми для закоммиченных определений.
