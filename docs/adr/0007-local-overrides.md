# ADR 0007: локальные переопределения

Статус: принято.

Переопределения находятся вне рабочей копии и поддерживают режимы `extend`, `replace` и `disable`. Приоритет: исходный источник < набор < закоммиченная конфигурация проекта < глобальная конфигурация пользователя < конфигурация пользователя для проекта. Обязательную политику ослабить нельзя.
