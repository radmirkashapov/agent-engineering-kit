# ADR 0006: корпоративная и пользовательская политика моделей

Статус: принято.

Непустой корпоративный список разрешённых моделей ограничивает закоммиченные определения. Пользовательские локальные модели расширяют только среду выполнения и не могут стать обязательной зависимостью в Git. Требования по возможности задаются через необходимые способности модели.
