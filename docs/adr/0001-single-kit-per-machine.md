# ADR-0001: один набор на машину

Статус: принято.

## Контекст

Копии политик в каждом репозитории расходятся и усложняют обновление клиентов.

## Решение

На машине используется одна рабочая копия для эксплуатации. Механизм разрешения путей с учётом платформы разделяет репозиторий, среду выполнения, память проектов и локальные переопределения. Рабочие проекты ссылаются на набор через тонкие клиентские адаптеры.

## Последствия

Обновление централизовано; сеанс фиксирует ревизию Git. Для разработки набора нужна отдельная ветка или рабочее дерево, а рабочая копия с незакоммиченными изменениями автоматически не обновляется.
