# ADR 0004: логический проект не равен Git-репозиторию

Статус: принято.

Идентичность задаётся в `.ai-team/project.yaml`. Один проект может состоять из одного репозитория, быть монорепозиторием, объединять несколько репозиториев или представлять произвольное рабочее пространство. Git-репозитории являются элементами его топологии.
