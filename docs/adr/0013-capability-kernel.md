# ADR 0013: ядро возможностей и рабочее пространство задачи

Статус: принято 12 октября 2026 года.

## Контекст

Kit должен одинаково обслуживать разные среды выполнения AI-агентов, монорепозитории и проекты из нескольких Git-репозиториев. Пользователь сохраняет локальную свободу, но конфигурация не должна выдавать декларативное разрешение за реально применённую защиту. Параллельные агенты и разработчики не должны незаметно перезаписывать одно рабочее дерево или часто изменяемые документы.

## Решение

Основой Kit становится ядро возможностей. Оно вычисляет действующую политику и происхождение решений, проверяет общие и проектные соглашения, компилирует профили разрешений и передаёт внешний контракт запуска выбранной среде выполнения. Манифест проекта остаётся необязательным; локальные описание и привязки позволяют подключить рабочую область без изменения исходных репозиториев.

Структура модулей обнаруживается автоматически по метаданным сборки. Манифест может уточнить владельца, критичность или добавить логическую границу, но не подменяет обнаружение. Для рабочей области из нескольких репозиториев Kit хранит локальные привязки, проверяет безопасный удалённый адрес и различает состояния `READY`, `DEGRADED`, `BLOCKED` и `MISMATCHED`.

Каждая параллельная задача получает рабочую область с вектором ревизий и объявленной областью записи. Локальная аренда запрещает пересекающуюся запись на одной машине. Управляемое рабочее дерево создаётся только явной командой и не изменяет основную рабочую копию. Между машинами координация выполняется через ветки Git, Pull Request, CI и очередь слияния. Освобождение аренды разрешено после явного завершения задачи, а сборка локального состояния — только после удаления рабочих деревьев и при отсутствии аренды.

Политика возможностей обязательна для каждого MCP. Штатная регистрация целого сервера разрешена, только если выбран весь объявленный набор инструментов. Частичный план сохраняется для объяснения, но не считается применённым разрешением. URL с учётными данными, параметрами запроса или фрагментом запрещены в версионируемой конфигурации.

## Последствия

- Kit остаётся управляющим слоем, а цикл агента принадлежит внешней среде выполнения.
- Local override может обойти restriction, но не технический invariant, path safety, secret hygiene или обязательное соглашение репозитория.
- Разработчик не обязан вручную перечислять каждый модуль, но обязан разрешить конфликты discovery и manifest refinements.
- Локальный lease не является распределённой блокировкой; организационная синхронизация между ПК остаётся в Git workflow.
- MCP со смешанными возможностями чтения и записи не работает в профиле только для чтения, если клиент не способен доказуемо применить список разрешённых инструментов.
